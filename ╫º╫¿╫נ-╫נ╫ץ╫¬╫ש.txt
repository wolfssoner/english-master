English Master 16: איך מעלים לאתר
==================================

מה יש בקובץ הזה
---------------
index.html             האפליקציה החדשה (גרסה 16). מחליפה את הקיים.
version.json           מחליף את הקיים. כולל את כל 22 השיעורים הקודמים, ואת המסלול החדש.
packs/test-1-12.txt    המסלול "מילים למבחן": כל 329 המילים משיעורים 1–12, 66 משפטים ו־50 קטעי קריאה.
sw.js, manifest.webmanifest, icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png
                       מאפשרים להתקין את האתר כאפליקציה בטלפון, ולפתוח אותו גם בלי אינטרנט.

העלאה (פעם אחת, כ־3 דקות)
-------------------------
1. נכנסים למאגר english-master ב־GitHub.
2. Add file ← Upload files.
3. גוררים את כל הקבצים והתיקייה packs ביחד (index.html, version.json, sw.js, manifest.webmanifest, 4 האייקונים, והתיקייה packs).
   GitHub מחליף קבצים קיימים עם אותו שם, ומוסיף את test-1-12.txt לתיקייה packs בלי לגעת בשיעורים הקיימים.
4. Commit changes.
5. אחרי דקה או שתיים, פותחים את האתר. אם עדיין רואים את הגרסה הישנה, מרעננים פעם אחת.

מה קורה אצל המשתמשים
--------------------
- מי שמשתמש באתר מקבל את גרסה 16 לבד. כל המילים, הסיפורים, השיעורים שהוסיפו וההתקדמות נשארים.
- מי שהוריד את הקובץ למחשב רואה "🎁 גרסה 16 זמינה" ומוריד קובץ חדש.
- במסך הבית מופיע "📝 מילים למבחן · שיעורים 1–12" עם כפתור הוסף.
  מי שעוד בגרסה 14 לא יראה את המסלול עד שיעדכן. זה בכוונה, כדי שהוא לא יותקן בצורה הישנה.

דברים שאפשר לשנות בלי גרסה חדשה
-------------------------------
- תאריך המבחן לכולם: בקובץ packs/test-1-12.txt, אחרי השורה ‎#אייקון 📝‎, מוסיפים שורה:
      #תאריך 2026-11-20
  והמסלול יראה לכל אחד כמה ימים נשארו וכמה מילים ללמוד היום.
  אם מוסיפים את התאריך אחרי שאנשים כבר הוסיפו את המסלול: ב־version.json, בשורה של test-1-12 ברשימה packs16,
  מוסיפים "ver":2. כולם יקבלו "🔄 עדכון לשיעור", והתאריך ייכנס בלי לגעת בהתקדמות.
  כל אחד יכול גם לקבוע תאריך לעצמו בתוך המסלול (⚙️).
- אחרי המבחן, להסיר את המסלול אצל כולם: ב־version.json מוסיפים לרשימה remove את "test-1-12".
  מילים שמישהו כבר תרגל יישארו אצלו במילון.
- הודעה לכולם: השדה "msg" ב־version.json, כמו קודם.
- להסתיר פיצ'ר אצל כולם: ב־version.json, בתוך "cfg", כותבים למשל "off":["duel"]. אפשר duel, songs או conf.
- כרטיס מוצמד במסך הבית: "pin":[{"id":"p1","title":"המבחן ביום חמישי","text":"...","btn":"למסלול","act":"col:test-1-12"}]
- שירים מומלצים לכולם: "songs":[{"title":"...","artist":"...","why":"...","url":"https://open.spotify.com/track/..."}]
- שיעור חדש בפורמט של גרסה 16 (עם #מסלול): מכניסים אותו לרשימה packs16 ב־version.json, ולא ל־packs.

תחרות אונליין
-------------
עובדת דרך שרתים ציבוריים לתקשורת בזמן אמת (EMQX, HiveMQ, Mosquitto). לא צריך הרשמה.
אם יום אחד אף אחד מהם לא יעבוד, אפשר להחליף בלי גרסה חדשה: ב־version.json בתוך "cfg": "mqtt":["wss://כתובת/mqtt"].

הוראות מלאות לכל הפקודות החדשות בחבילה: הגדרות ← 🔐 ניהול תוכן ← ⬇ תבנית ריקה.
