# English Master

אפליקציה ללימוד אנגלית בעברית: חזרות חכמות, קריאה עם תרגום בלחיצה, מבחנים, משחקים, צ׳אט AI, כמה חשבונות וסנכרון מוצפן לענן דרך GitHub.

## העלאה ל־GitHub Pages

1. צור מאגר חדש ב־GitHub (למשל `english-master`).
2. העלה את כל הקבצים בתיקייה הזו לשורש המאגר:
   `index.html`, `version.json`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-512-maskable.png`, `apple-touch-icon.png`.
3. ב־**Settings ← Pages** בחר `Deploy from a branch`, ענף `main`, תיקייה `/ (root)`, ושמור.
4. אחרי כדקה האתר זמין בכתובת `https://USERNAME.github.io/english-master/`.
5. בטלפון: פתח את הכתובת ב־Chrome ← תפריט ⋮ ← **הוסף למסך הבית**. האפליקציה תיפתח במסך מלא ותעבוד גם בלי אינטרנט.

## עדכון גרסה

1. מעלים את `index.html` החדש ואת `version.json` עם מספר הגרסה החדש (למשל `"v":"13.1"`).
2. כל מי שפותח את האפליקציה רואה "🎁 גרסה חדשה זמינה" ולוחץ "עדכן עכשיו". הנתונים שלו נשמרים.

האתר תמיד מנסה קודם את הגרסה החדשה ברשת, ורק בלי אינטרנט משתמש בעותק השמור.

## הודעות מהמשתמשים

דיווחי באגים, דוחות "שליחה למורה" ותוצאות מבחנים משותפים נשלחים לגיליון Google שלך (Apps Script), כל סוג בלשונית נפרדת: bug, report, exam.

## שיעור חדש (חבילת תוכן)

1. באפליקציה: הגדרות ← 🔐 ניהול תוכן ← קוד. כותבים חבילה לפי התבנית, לוחצים "בדוק" ומתקנים מה שצריך.
2. "שמור כקובץ לפרסום" ← מעלים את הקובץ למאגר לתיקייה `packs/` (בשדה השם כותבים `packs/` לפני שם הקובץ).
3. ב־`version.json` מוסיפים לרשימה `packs` שורה כמו: `{"id":"lesson10","title":"שיעור 10","file":"packs/lesson10.txt"}`
4. כל המשתמשים רואים "📦 שיעור חדש זמין" ומוסיפים בלחיצה.

## הודעה לכל המשתמשים

ב־`version.json` כותבים בשדה `"msg"` טקסט, למשל `"msg":"השיעור מחר ב־18:00"`. מוצג במסך הבית עד שסוגרים. ריק = לא מוצג.

## הנתונים

- הכול נשמר בדפדפן של כל משתמש. לאתר אין שרת ואין מעקב.
- כל משתמש יכול לחבר את החשבון שלו ל־GitHub שלו, בתוך האפליקציה: הגדרות ← חשבונות וענן. הנתונים מוצפנים במכשיר (AES-256-GCM) לפני שהם נשמרים כ־Gist סודי.
- מעבר מקובץ מקומי לאתר: קודם ייצא גיבוי (או סנכרן לענן) בקובץ המקומי, ואז ייבא אותו (או התחבר לענן) באתר.

מדריך מלא נמצא בתוך האפליקציה: הגדרות ← מדריך מלא.
